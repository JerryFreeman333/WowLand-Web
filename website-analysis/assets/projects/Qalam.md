## infos

WebGL advocate and TiltBrush workflow designer for Google's Qalam Creator at Stink Studios, celebrating Ramadan through interactive Arabic calligraphy. Reverse engineered TiltBrush's 3D painting system to faithfully recreate artwork by iconic Arabic artists like eL Seed in an accessible web platform. Developed custom conversion pipeline reducing high-end VR file sizes for mobile-friendly delivery while preserving the authentic qualities of each brush stroke.
